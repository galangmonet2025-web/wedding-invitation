## Aturan Sebelum Mulai

1. **Jangan ubah strategi sebelum 20 postingan.** Data di bawah itu tidak berarti.
2. **Kalau ada konten tembus 3× rata-rata → buang jadwal, buat 5 variasinya.** Jadwal ini pelayan, bukan majikan.
3. **Setiap video masuk ke 4 platform**: TikTok (asli) → IG Reels → FB Reels → YT Shorts.
4. **Story IG & Status WA jalan tiap hari** terlepas dari jadwal video.
5. **Sabtu = hari rekam borongan. Minggu = hari edit & jadwal.**

## Template Spreadsheet Bank Konten

Buat di Google Sheets. Kolomnya:

| Kolom | Isi |
|---|---|
| No | nomor naskah |
| Judul | nama pendek |
| Kategori | A/B/C/D/E |
| Status | Ide / Direkam / Diedit / Dijadwalkan / Terbit |
| File | link Drive |
| Tanggal terbit | |
| TikTok: tayangan | |
| TikTok: tonton selesai % | |
| TikTok: simpan+bagikan | |
| IG: tayangan | |
| Chat WA masuk | ← **kolom terpenting** |
| Catatan | kenapa jalan / kenapa gagal |

> Kolom **"Chat WA masuk"** adalah satu-satunya yang benar-benar mengukur uang. Isi jujur.

## Target 60 Hari (Realistis, Bukan Mimpi)

| Metrik | Konservatif | Bagus | Sangat bagus |
|---|---|---|---|
| Follower TikTok | 1.000 | 3.000 | 8.000+ |
| Follower IG | 300 | 800 | 2.000+ |
| Total tayangan | 100rb | 400rb | 1jt+ |
| Chat WA masuk | 15 | 40 | 100+ |
| **Closing** | **3** | **10** | **25+** |

**Kalau angka konservatif pun tidak tercapai**, periksa berurutan:
1. Apakah kamu benar-benar posting tiap hari? (paling sering ini penyebabnya)
2. Apakah hook di 1,5 detik pertama sudah cukup mengejutkan?
3. Apakah pakai audio tren?
4. Apakah profil terlihat profesional saat dicek? (bio, highlight, 9 postingan teratas)
5. Apakah komentar dibalas dalam 1 jam?

**Kalau tayangan tinggi tapi chat nol** — masalahnya bukan di konten, tapi di CTA & profil. Perbaiki bio, link, dan tambahkan CTA yang lebih tegas.
